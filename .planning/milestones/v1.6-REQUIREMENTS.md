# Requirements: Generateur de Fiches Techniques Delagrave

**Defined:** 2026-02-16
**Core Value:** Un utilisateur soumet un devis PDF et obtient automatiquement un dossier PowerPoint complet de fiches techniques — sans intervention manuelle.

## v1.6 Requirements

Requirements pour le deploiement multi-postes. Chaque requirement mappe a une phase du roadmap.

### Configuration

- [x] **CFG-01**: Le systeme lit un fichier `gendoc.json` local pour connaitre le chemin du dossier partage reseau — Phase 22 (config_loader.py avec recherche CWD/home/dev)
- [x] **CFG-02**: Si le fichier config n'existe pas au demarrage, le serveur MCP signale une erreur claire avec instructions — Phase 22 (ConfigurationError avec example JSON)
- [x] **CFG-03**: Le systeme valide au demarrage que le dossier partage est accessible et contient les donnees attendues (references/, images/, template) — Phase 22 (validation startup fail-fast)

### Output

- [x] **OUT-01**: Chaque generation de devis cree un sous-dossier dedie dans `./output/{numero_devis}/` — Phase 23 (_get_devis_output_dir + _sanitize_devis_numero)
- [x] **OUT-02**: Le fichier PowerPoint genere est ecrit dans le sous-dossier du devis — Phase 23 (generate_slides auto-compute ./output/{devis}/fiches.pptx)
- [x] **OUT-03**: Le LOG.md de l'execution est ecrit dans le sous-dossier du devis — Phase 23 (PipelineLogger refactored)
- [x] **OUT-04**: Le SP selector HTML et le JSON d'export sont ecrits dans le sous-dossier du devis — Phase 23 (open_sp_selector + load_sp_selection auto-path)

### Controle d'acces

- [x] **ACL-01**: Le fichier config contient un flag `admin` (true/false) — Phase 22+24 (config_loader default false + _require_admin)
- [x] **ACL-02**: Les outils CRUD (add_reference, update_reference, delete_reference) sont desactives quand admin=false — Phase 24 (_require_admin guard)
- [x] **ACL-03**: Un message d'erreur clair est retourne si un utilisateur non-admin tente une operation CRUD — Phase 24 ("Operation reservee a l'administrateur")

### Deploiement

- [x] **DEP-01**: Le package Python peut etre installe/execute depuis un dossier copie localement — Phase 25 (pip install -e . verifie)
- [x] **DEP-02**: La configuration MCP pour Claude CLI est documentee et reproductible — Phase 25 (.mcp.json.example cree)
- [x] **DEP-03**: Un script ou guide de deploiement permet de configurer un nouveau poste — Phase 25 (DEPLOY.md + install.ps1 + PDF 19 pages)

### Non-regression

- [x] **REG-01**: Tous les 123 tests existants passent apres la refactorisation des chemins — Verifie (138 tests, zero regressions)
- [x] **REG-02**: Tests specifiques pour la resolution des chemins depuis la config — Phase 22 (8 config_loader + 4 server_config tests)
- [x] **REG-03**: Tests pour le mode admin vs utilisateur — Phase 24 (3 admin guard tests dans test_mcp_server_config.py)

## Future Requirements

Differes des milestones precedents, hors scope v1.6.

- **GEN-01**: Modes de generation CHI/DOE/FTI
- **GEN-02**: Integration des fiches-existantes (.pptx pre-existants)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Installation via pip/registry | Deploiement par copie locale suffit pour le nombre de postes |
| Interface web d'administration | L'admin utilise Claude CLI comme les autres |
| Gestion des permissions Windows (ACL filesystem) | Le flag admin dans la config suffit |
| Mise a jour automatique du code | Copie manuelle ou script de deploiement |
| Multi-tenancy (plusieurs catalogues) | Un seul catalogue partage par tous |
