**Status:** SHIPPED 2026-02-10

## Milestone Summary

**Key Decisions:**
- MD comme source de verite (decouple des macros Excel, versionnable)
- Serveur MCP unique FastMCP (pas scripts separes)
- python-pptx avec .potm trick (conversion zipfile pour contourner limitation)
- Texte revetement split en 3 zones (TEXTE, MISE_EN_OEUVRE, FINITION)
- Auto-shrink TEXT_TO_FIT_SHAPE sur tous les placeholders texte

**Issues Resolved:**
- Template .potm non lisible par python-pptx (conversion zip)
- Template blank slide before cover page (removal after load)
- Revetement text overflow (text splitting + auto-size)
- Empty placeholder "Cliquez pour ajouter" prompts (element removal)

**Technical Debt:**
- GEN-09 (modes CHI/DOE/FTI) deferred — un seul format de sortie
- add_reference MCP tool is a stub (not implemented)
- Fiches-existantes family not integrated (pre-existing .pptx files)
