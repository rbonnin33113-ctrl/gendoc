Create src/gendoc/utils/config_loader.py with:

1. **Config Search Strategy** (in order):
   - Look for gendoc.json in current working directory
   - Look for gendoc.json in user home directory (~/.gendoc.json)
   - Look for gendoc.json alongside server.py (fallback for dev)

2. **load_config() function**:
   - Searches for config file using strategy above
   - If not found: raise ConfigurationError("Config file not found. Create gendoc.json with: {\"network_share_path\": \"path/to/shared/Delagrave\", \"admin\": false}")
   - Reads JSON and validates structure
   - Returns dict with config data + resolved paths

3. **Validation**:
   - Require "network_share_path" field (string, non-empty)
   - Optional "admin" field (boolean, defaults to false)
   - Validate network_share_path exists and is accessible (Path.exists())
   - Validate required subdirectories exist: references/, images/, "Modele fiches - Powerpoint/"
   - Validate template file exists: "Modèle fiche technique vide - Ind J.potm"
   - If validation fails: raise ConfigurationError with specific missing path

4. **Return Structure**:
```python
{
    "config_path": Path,          # Where config was found
    "network_share_path": Path,   # Base path from config
    "references_dir": Path,       # network_share_path / "references"
    "images_dir": Path,           # network_share_path / "images"
    "template_path": Path,        # network_share_path / "Modele fiches - Powerpoint" / "Modèle fiche technique vide - Ind J.potm"
    "admin": bool                 # From config or default False
}
```

5. **ConfigurationError Exception**:
   - Custom exception class for clear error messages
   - Used by MCP server to return user-friendly errors

Implementation notes:
- Use pathlib.Path for all path operations
- Use json.load() for reading config
- Template name exactly: "Modèle fiche technique vide - Ind J.potm" (with accent on e)
- Make error messages actionable (tell user what to create/fix)
