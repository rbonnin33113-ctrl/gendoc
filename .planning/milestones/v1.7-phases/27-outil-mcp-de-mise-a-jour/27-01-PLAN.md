Creer `src/gendoc/utils/auto_updater.py` avec une fonction principale `run_update()` et des fonctions utilitaires internes.

**Fonction principale:**
```python
def run_update(
    github_repo: str,
    github_token: str | None = None,
    install_dir: str | None = None,
) -> dict:
```

**Parametres:**
- `github_repo`: format "owner/repo" (lu depuis gendoc.json par l'appelant)
- `github_token`: token GitHub optionnel pour repo prive (lu depuis gendoc.json)
- `install_dir`: repertoire ou le repo est clone/installe. Si None, deduire depuis le package installe en remontant depuis `__file__` (4 niveaux: auto_updater.py -> utils -> gendoc -> src -> racine_repo). Si la racine trouvee ne contient pas pyproject.toml, utiliser `C:\gendoc` comme fallback.

**Valeur de retour (dict):**
```python
{
    "status": "success" | "error" | "no_repo",
    "old_version": "2.0.0",      # version avant update (via get_local_version)
    "new_version": "2.1.0",      # version apres update (re-read pyproject.toml)
    "steps_completed": ["git_pull", "pip_install"],  # etapes reussies
    "error": None | "message",   # None si succes
    "needs_restart": True,        # toujours True apres pip install
    "resume": "Mise a jour OK: v2.0.0 -> v2.1.0. Redemarrez Claude pour appliquer."
}
```

**Sous-fonctions internes (prefixees _):**

1. `_is_git_installed() -> bool` :
   - Execute `subprocess.run(["git", "--version"], capture_output=True, timeout=10)`
   - Retourne True si returncode == 0, False sinon (FileNotFoundError = False aussi)

2. `_install_git() -> dict` :
   - Execute `subprocess.run(["winget", "install", "--id", "Git.Git", "-e", "--source", "winget", "--accept-package-agreements", "--accept-source-agreements"], capture_output=True, timeout=300)`
   - Si succes (returncode 0), retourne `{"ok": True}`
   - Si echec, retourne `{"ok": False, "error": "message stderr"}`
   - Note importante dans un commentaire: apres installation winget, le PATH du processus actuel ne contient PAS encore Git. Les appels git suivants doivent utiliser le chemin complet `C:\Program Files\Git\cmd\git.exe` OU un nouveau subprocess avec `shell=True` pour heriter du PATH systeme mis a jour. Approche choisie: utiliser `_get_git_cmd()` qui retourne le chemin complet si Git vient d'etre installe via winget.

3. `_get_git_cmd() -> str` :
   - Si `_is_git_installed()` retourne True, retourner "git"
   - Sinon, verifier si `C:\Program Files\Git\cmd\git.exe` existe et le retourner
   - Si aucun ne fonctionne, lever RuntimeError

4. `_clone_repo(git_cmd: str, github_repo: str, github_token: str | None, target_dir: str) -> dict` :
   - Construit l'URL: si token, `https://{token}@github.com/{repo}.git`, sinon `https://github.com/{repo}.git`
   - Execute `subprocess.run([git_cmd, "clone", url, target_dir], capture_output=True, timeout=120)`
   - Retourne `{"ok": True}` ou `{"ok": False, "error": "stderr content"}`

5. `_pull_repo(git_cmd: str, repo_dir: str) -> dict` :
   - Execute `subprocess.run([git_cmd, "pull"], capture_output=True, timeout=60, cwd=repo_dir)`
   - Retourne `{"ok": True, "output": "stdout"}` ou `{"ok": False, "error": "stderr"}`

6. `_pip_install(repo_dir: str) -> dict` :
   - Execute `subprocess.run([sys.executable, "-m", "pip", "install", "-e", "."], capture_output=True, timeout=120, cwd=repo_dir)`
   - Utilise `sys.executable` pour cibler le bon Python (pas un autre dans le PATH)
   - Retourne `{"ok": True}` ou `{"ok": False, "error": "stderr"}`

7. `_read_version_from_pyproject(repo_dir: str) -> str` :
   - Lit `{repo_dir}/pyproject.toml` et extrait la version avec regex `^version\s*=\s*"([^"]+)"`
   - Retourne "0.0.0" si echec

**Logique principale de run_update():**

```
1. Si github_repo vide/absent -> return {"status": "no_repo", ...}
2. old_version = get_local_version()
3. Deduire install_dir si None
4. steps_completed = []
5. Si le dossier install_dir ne contient PAS .git:
   a. Verifier si Git est installe
   b. Si non: _install_git(), ajouter "git_installed" aux steps
   c. git_cmd = _get_git_cmd()
   d. _clone_repo(git_cmd, ..., install_dir)
   e. Ajouter "git_clone" aux steps
6. Sinon (.git existe):
   a. git_cmd = _get_git_cmd()
   b. _pull_repo(git_cmd, install_dir)
   c. Ajouter "git_pull" aux steps
7. _pip_install(install_dir)
8. Ajouter "pip_install" aux steps
9. new_version = _read_version_from_pyproject(install_dir)
10. Retourner dict succes avec resume en francais
```

**Gestion d'erreur:** Chaque sous-etape qui echoue cause un return immediat avec `status: "error"`, le message d'erreur explicite en francais, et les steps_completed jusqu'ici. Ne JAMAIS laisser une exception non attrapee remonter -- tout dans try/except avec messages clairs.

**Resume (champ resume):**
- Succes: "Mise a jour OK: v{old} -> v{new}. Redemarrez Claude pour appliquer."
- Succes sans changement de version: "Deja a jour (v{version}). Aucun changement."
- Erreur Git absent + winget echec: "Git non installe et installation automatique echouee. Installez Git manuellement: https://git-scm.com/download/win"
- Erreur clone: "Echec du clone GitHub. Verifiez le token dans gendoc.json et la connexion reseau."
- Erreur pull: "Echec de git pull. Conflit possible -- contactez l'administrateur."
- Erreur pip: "git pull OK mais pip install echoue. Essayez manuellement: pip install -e {dir}"
- Pas de repo: "Mise a jour impossible: github_repo non configure dans gendoc.json"

**Patterns a suivre:**

- subprocess.run avec capture_output=True et timeout partout
- Encodage stderr/stdout avec `.decode("utf-8", errors="replace")` pour eviter UnicodeDecodeError sur Windows
