# Milestone v1.2: Outil de Selection SP

**Status:** SHIPPED 2026-02-11
**Phases:** 9-11
**Total Plans:** 3

## Overview

Permettre a l'utilisateur de visualiser, selectionner et editer les articles speciaux (SP) d'un devis via une page HTML interactive, avec extraction automatique des designations depuis le PDF et integration MCP file-based.

**Plans**: 1 plan

**Plans**: 1 plan

## Milestone Summary

**Key Decisions:**
- Decision: Designation extraction stops at next article code (all uppercase OR contains hyphen) — prevents false positives
- Decision: Strip quantity indicators (UN \d+) from designation text — quantity is order-specific, not product characteristic
- Decision: Partial export allowed — user not forced to configure all SP articles
- Decision: File-based MCP workflow (HTML to disk, JSON from disk) — enables human-in-the-loop editing
- Decision: Custom products must be in product_codes list — existing generate_slides architecture preserved

**Issues Resolved:**
- SP codes (SPMOB, SPPAIL, SPTABLEEN, SPUSE) falling into inconnus instead of speciaux
- Article code detection pattern too permissive (matched regular words like "Dimension")

**Issues Deferred:**
- ADV-01: Modes de generation CHI/DOE/FTI
- ADV-02: Integration des fiches-existantes (.pptx pre-existants)
- ADV-03: Implementation complete de add_reference
- ADV-04: Synchronisation automatique Excel -> MD
