**Part A: Add `preview_generation` MCP tool to server.py**

Add a new MCP tool `preview_generation` in `src/gendoc/mcp/server.py` that takes analyze_devis output and builds a structured preview of what the generation would produce. This gives the user a clear picture before committing to generation.

1. Add import at top: `from gendoc.parsers.md_parser import find_product` (already imported via other imports -- verify; if not, add it).

2. Add the tool between `analyze_devis` and `generate_slides`:

```python
@mcp.tool()
async def preview_generation(analysis_result: dict) -> str:
    """
    Build a structured preview of what PowerPoint generation would produce.

    Takes the output of analyze_devis and returns a detailed preview with:
    - Product references grouped by family with titles
    - Coatings that will be auto-generated
    - Unknown codes that will be skipped
    - Estimated page count

    Args:
        analysis_result: Dictionary from analyze_devis (header, references, revetements, forfaits, inconnus)

    Returns:
        JSON string with preview data: families (with products), revetements, inconnus, estimated_pages, suggested_filename
    """
```

Implementation details:
- Import `FAMILY_ORDER, FAMILY_DISPLAY_NAMES` from `gendoc.generators.document_assembler` (lazy import inside function body to avoid circular deps).
- Extract `references` list from analysis_result. For each reference, call `find_product(ref['code'], REFERENCES_DIR)` to get the product title (handle base code lookup for coating suffixes: if code has `-GE` etc., strip it).
- Group references by family, ordered by FAMILY_ORDER.
- Build the preview structure:
  ```python
  {
      "header": analysis_result.get("header", {}),
      "families": [
          {
              "name": family_key,
              "display_name": FAMILY_DISPLAY_NAMES[family_key],
              "products": [
                  {"code": ref["code"], "titre": product_title, "revetement": ref.get("revetement")}
              ]
          }
          # for each family that has products, in FAMILY_ORDER
      ],
      "revetements": analysis_result.get("revetements", []),
      "forfaits": analysis_result.get("forfaits", []),
      "inconnus": analysis_result.get("inconnus", []),
      "estimated_pages": cover(1) + toc(1) + sum(1 separator + N products per family) + len(revetements),
      "suggested_filename": f"fiches_{numero_devis.replace(' ', '')}.pptx" if numero_devis else "fiches_techniques.pptx"
  }
  ```
- Return as JSON string.
- Wrap in try/except, return `{"error": "..."}` on failure.
