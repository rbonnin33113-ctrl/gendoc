**Class TestCRUDIntegration (1 comprehensive test):**

`test_full_lifecycle_add_lookup_update_delete`:
This test validates the complete CRUD lifecycle using a temporary references directory.

Steps:
1. **Setup**: Create a temp directory structure mimicking `Delagrave/references/` and `Delagrave/images/`. Create a minimal `_parametrage.md` file (can be empty).
2. **ADD**: Use `append_product_to_family` to add a product with code `INTEG-TEST-001`, titre `Integration Test Product`, famille `test-integ`, texte `Description for integration test`.
3. **LOOKUP**: Use `find_product("INTEG-TEST-001", tmp_references_dir)` from md_parser. Assert product is found. Assert product['titre'] == 'Integration Test Product'. Assert product['famille'] == 'test-integ'.
4. **ENSURE INFRASTRUCTURE**: Call `ensure_family_infrastructure("test-integ", tmp_references_dir)`. Assert images directory exists.
5. **UPDATE**: Use `update_product_in_family` to update titre to `Integration Test Product Updated`. Read back with `find_product`. Assert new titre.
6. **IMAGE COPY**: Create a temp PNG file (just write some bytes). Call `copy_product_images` with the temp file path. Assert file exists in target images dir.
7. **DELETE**: Use `remove_product_from_family` to delete the product. Assert returned product has code `INTEG-TEST-001`.
8. **VERIFY DELETED**: Use `find_product("INTEG-TEST-001", tmp_references_dir)`. Assert returns None.
9. **CLEANUP**: `tmp_path` handles cleanup automatically.

The test must create a proper directory structure:
```
tmp_path/
  references/
    test-integ.md  (created by append_product_to_family)
    _parametrage.md  (empty file for md_parser compatibility)
  images/
    test-integ/  (created by ensure_family_infrastructure or copy_product_images)
```

Note: `find_product` from md_parser iterates all `.md` files in the references directory. It uses `get_all_family_files` which excludes `_index.md`, `_parametrage.md`, and `_entreprise.md`. So the temp directory just needs the family MD file.

IMPORTANT: `find_product` accepts `references_dir` as its second argument. The temp directory must be structured correctly for it to find the family MD file.
