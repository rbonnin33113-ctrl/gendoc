Refactor the existing `_reload_generators()` function in server.py to add mtime-based change detection and logging. Specific changes:

1. **Add module mtime tracking dict** at module level:
   ```python
   _module_mtimes: dict[str, float] = {}
   ```
   This stores the last-known mtime for each generator module file path.

2. **Refactor `_reload_generators()`** to:
   a. Build a list of the 3 generator module objects: `gendoc.generators.modern_template`, `gendoc.generators.document_assembler`, `gendoc.generators.pptx_generator`
   b. For each module, get the file path via `module.__file__`, then get current mtime via `os.path.getmtime()`
   c. Compare against `_module_mtimes[path]` — if different (or first call), call `importlib.reload(module)` and update the stored mtime
   d. Log reloaded modules: use `print()` with format `[gendoc hot-reload] Reloaded {module_name} ({timestamp})` where timestamp is ISO format (datetime.now().isoformat(timespec='seconds'))
   e. If NO modules were reloaded, do NOT print anything (silent when unchanged)
   f. Return `gendoc.generators.pptx_generator.generate_presentation` (the potentially-refreshed function reference)

3. **Add `_reload_assembler_constants()`** helper that:
   a. Calls `_reload_generators()` (which handles mtime check internally)
   b. Returns a tuple `(FAMILY_ORDER, FAMILY_DISPLAY_NAMES)` freshly read from the reloaded `document_assembler` module
   c. This replaces the local import in `preview_generation`

4. **Update `preview_generation` tool** (around line 169):
   - Replace `from gendoc.generators.document_assembler import FAMILY_ORDER, FAMILY_DISPLAY_NAMES` with a call to `_reload_assembler_constants()` to get fresh values
   - This ensures preview also picks up changes to family ordering/names

5. **Clean up unused import** on line 23:
   - Remove `from gendoc.generators.pptx_generator import generate_presentation as run_generate_presentation` since `generate_slides` now uses `_reload_generators()` to get the function reference

6. **Add `import os` and `from datetime import datetime`** at the top of the file (needed for mtime and timestamp).

Important: Keep the reload ORDER as-is (modern_template first, then document_assembler, then pptx_generator) because pptx_generator imports from the others, so they must be reloaded first for the re-import to pick up their changes.
