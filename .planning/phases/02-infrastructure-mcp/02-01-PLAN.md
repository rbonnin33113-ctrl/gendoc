**`server.py`:** A FastMCP server that exposes 6 tools. Use `from fastmcp import FastMCP` (fastmcp 2.14.5 is installed).

The server must:
1. Create a `FastMCP` instance named "gendoc" with a description
2. Resolve the references directory as `Path(__file__).resolve().parent.parent.parent.parent / "Delagrave" / "references"` (i.e., relative to the project root, not CWD — this is crucial for MCP servers that may be started from any directory). Store this as a module-level constant `REFERENCES_DIR`.
3. Expose 6 tools using `@mcp.tool()` decorator:

**Reference tools (use md_parser functions):**
- `lookup_reference(code: str) -> str`: Call `find_product(code, REFERENCES_DIR)`. Return JSON-serialized product dict if found, or a "not found" message. Import `json` for serialization.
- `list_families() -> str`: Call `get_all_families(REFERENCES_DIR)`. Return JSON with family names and counts, plus total.
- `search_references(query: str) -> str`: Call `search_products(query, REFERENCES_DIR)`. Return JSON list of matching products (code, ref, titre, famille only — not full data to keep responses concise).

**Stub tools (Phase 3 and 4 will implement):**
- `analyze_devis(pdf_path: str) -> str`: Return a stub message: "Analyze devis tool registered. Full implementation in Phase 3. Received path: {pdf_path}"
- `generate_slides(product_codes: list[str], output_path: str, mode: str = "FTI") -> str`: Return a stub message: "Generate slides tool registered. Full implementation in Phase 4. Received {len(product_codes)} codes, output: {output_path}, mode: {mode}"
- `add_reference(family: str, code: str, ref: str, titre: str, texte: str = "") -> str`: Return a stub message: "Add reference tool registered. Full implementation in Phase 3. Would add {code} to {family}"

4. Add a `__main__` block at the bottom:
```python
if __name__ == "__main__":
    mcp.run(transport="stdio")
```

- All tool functions must have clear docstrings (these become the tool descriptions Claude sees)
- Use `from gendoc.parsers.md_parser import find_product, get_all_families, search_products, find_products_by_family` at the top of the file

- For `lookup_reference`, serialize the full product dict to JSON with `ensure_ascii=False` and `indent=2` for readability
- For `search_references`, limit to first 50 results to avoid massive responses
- For `list_families`, include a "total" key summing all product counts
- Return type for all tools is `str` (MCP tools return text content)
