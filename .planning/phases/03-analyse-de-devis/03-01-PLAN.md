  <action>
Creer `src/gendoc/parsers/devis_parser.py` avec une fonction `parse_devis(pdf_path: str) -> dict` qui:

1. Ouvre le PDF avec pdfplumber (deja installe, pas besoin de pip install)
2. Parcourt chaque page en extrayant le texte ET les tables
3. Detecte la structure du devis Delagrave:
   - Page de garde (page 1): ignorer
   - Pages de contenu (page 2+): colonnes Article | Designation | Unite | Qte | Prix total HT | EC*
   - Page recapitulatif ("Recapitulatif des conditions"): ignorer
   - Pages CGV ("CONDITIONS GENERALES DE VENTE"): ignorer

4. Pour chaque page de contenu, extraire:
   - **Lignes de section** (ex: "PAILLASSE HUMIDE", "PAILLASSE SECHE", "FORFAITS"): detectees par texte en majuscules sans code article, en debut de bloc. Les stocker comme contexte de section.
   - **Lignes de sous-section** (ex: "Prof utile 750mm avec dosseret"): texte en italique ou souligne dans la colonne Designation, sans code article. Stocker comme sous-contexte.
   - **Lignes produit**: ont un code dans la colonne Article (ex: "PM-D-H-75-GE", "SPMSE-1967"), une designation, une unite, une quantite. Les extraire.
   - **Lignes a ignorer**: "Sous-total..." (italique), "Total..." (gras), lignes vides

5. Retourner un dictionnaire:
```python
{
    "numero_devis": "25 64 0637",  # extrait de l'en-tete
    "date": "20/10/2025",           # extrait de l'en-tete
    "client": "INOVIE BIOPYRENEES", # extrait de l'en-tete
    "sections": [
        {
            "nom": "PAILLASSE HUMIDE",
            "sous_section": "Prof utile 750mm avec dosseret",
            "lignes": [
                {"code": "PM-D-H-75-GE", "designation": "Paillasse Murale...", "unite": "ML", "quantite": 8.23},
                {"code": "SPMSE-1967", "designation": "Plage technique...", "unite": "ML", "quantite": 8.23},
                ...
            ]
        },
        ...
    ],
    "references_extraites": [
        {"code": "PM-D-H-75-GE", "quantite": 8.23, "section": "PAILLASSE HUMIDE"},
        {"code": "PM-D-H-75-GE", "quantite": 2.40, "section": "PAILLASSE SECHE"},
        ...
    ]
}
```

6. `references_extraites` est une liste aplatie de TOUS les codes article trouves, avec leur quantite et section d'origine. Un meme code peut apparaitre plusieurs fois (sections differentes).

7. Filtrer les sections "FORFAITS" de `references_extraites` (les codes forfait comme FPORT, FORPOSE1J ne sont pas des references produit). Garder la section dans `sections` pour info, mais pas dans `references_extraites`.

**Approche technique pour le parsing PDF:**
- Utiliser `pdfplumber` avec `page.extract_table()` pour les pages tabulaires
- Si `extract_table()` ne donne pas de bons resultats, fallback sur `page.extract_text()` avec parsing regex ligne par ligne
- Le format du devis est tabulaire avec des colonnes fixes, donc `extract_table()` devrait bien fonctionner
- Pour l'en-tete (page 1): utiliser `extract_text()` et des regex pour numero, date, client
- Pattern pour detecter un code article: la cellule Article contient du texte alphanumerique (pas vide, pas "Total", pas "Sous-total")
- Pattern pour detecter une section: ligne ou la cellule Article est vide mais Designation contient un texte en majuscules type "PAILLASSE HUMIDE"
- Pattern pour les forfaits: section dont le nom contient "FORFAIT"

**Ajouter `pdfplumber>=0.10.0` aux dependencies dans pyproject.toml.**

Le module est une pure library (pas de print/input, comme md_parser.py). Ajouter un bloc `if __name__ == "__main__"` minimal pour test CLI:
```python
if __name__ == "__main__":
    import sys, json
    result = parse_devis(sys.argv[1])
    print(json.dumps(result, ensure_ascii=False, indent=2))
```
