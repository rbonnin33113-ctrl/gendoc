Creer `src/gendoc/parsers/devis_analyzer.py` — module pur (pas de print/I/O) qui orchestre l'analyse complete.

**Structure du resultat (dict retourne par analyze_devis):**
```python
{
    "header": {"numero_devis": "25 64 0637", "date": "20/10/2025", "client": "INOVIE BIOPYRENEES"},
    "references": [
        {"code": "PM-D-H-75-GE", "famille": "paillasse", "revetement": "GE"},
        {"code": "SPMSE-1967", "famille": "equipement", "revetement": None},
        {"code": "CU12V", "famille": "equipement", "revetement": None},
        ...
    ],
    "revetements": [
        {"code": "GE", "titre": "GE - Glace emaillee"}
    ],
    "forfaits": ["FPORT", "FORPOSE1J"],
    "inconnus": ["PASCAB80"]  # codes non trouves dans les MD
}
```

**IMPORTANT — Decision utilisateur: PAS de quantites.** Chaque code apparait une seule fois dans le resultat. `PM-D-H-75-GE` present dans 2 sections du devis = 1 seule entree.

**Fonctions a implementer:**

1. `extract_article_codes(pages_text: list[str]) -> list[str]` — Extrait les codes article uniques du texte.
   - Un code article est le PREMIER mot d'une ligne dans les pages de produits (pages 2+, pas page 1 ni les pages de recap/conditions).
   - Pattern: debut de ligne, un code alphanum avec tirets possibles (ex: `PM-D-H-75-GE`, `SPMSE-1967`, `CU12V`, `EU40`, `FL12`, `FPORT`).
   - Exclure les lignes qui sont clairement des en-tetes de section (tout en majuscules sans tiret comme "PAILLASSE HUMIDE", "FORFAITS") — ces lignes sont des titres de chapitre, pas des codes article.
   - Exclure les lignes contenant "Page", "Sous-total", "Total", "Article", "SAS DELAGRAVE".
   - Retourner les codes uniques (set -> sorted list) pour deduplication.

2. `classify_codes(codes: list[str], references_dir: Path) -> dict` — Classifie chaque code.
   - Pour chaque code:
     a. D'abord tenter un lookup direct via `md_parser.find_product(code, references_dir)`.
     b. Si pas trouve, tester si le code a un suffixe de revetement: les 12 codes revetement sont DA, GE, GED, GR, IN, PP, RP, RP6, RPR, RS, SP, ST. Si le code se termine par `-{SUFFIX}` ou ce suffix est l'un de ces 12, tenter un lookup sans le suffixe (ex: `PM-D-H-75-GE` -> lookup `PM-D-H-75`).
     c. Si le code ressemble a un forfait (commence par "F" et est court type FPORT, FORPOSE1J, ou contient "POSE", "PORT", "TRANSPORT"), le mettre dans forfaits.
     d. Sinon, le mettre dans inconnus.
   - **Sorbonnes autoportantes**: Les sorbonnes (famille "sorbonne") dont le titre contient "Autoportante" necessitent un revetement. Pour ces produits, lire la dimension "Liste des revetements" dans les donnees produit pour determiner les revetements possibles. Ajouter `revetement: "auto"` pour signaler que le revetement doit etre choisi (pas de suffixe dans le code pour les sorbonnes — le revetement est determine a la commande).
   - Pour la liste `revetements`: collecter tous les codes revetement uniques detectes (via suffixes des paillasses ET sorbonnes autoportantes), et pour chacun faire un lookup dans revetement.md pour obtenir le titre.

3. `analyze_devis(pdf_path: Path, references_dir: Path) -> dict` — Fonction principale.
   - Appelle `pdf_parser.extract_text(pdf_path)` pour obtenir le texte brut.
   - Appelle `pdf_parser.extract_header(pages_text)` pour le header.
   - Appelle `extract_article_codes(pages_text)` pour les codes.
   - Appelle `classify_codes(codes, references_dir)` pour la classification.
   - Retourne le dict structure complet.
   - En cas d'erreur PDF (fichier invalide), lever l'exception — ne pas l'avaler.

**Imports necessaires:**

from gendoc.parsers.md_parser import find_product, parse_family_md, get_all_family_files
