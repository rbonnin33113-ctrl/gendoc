  <action>
Creer `src/gendoc/parsers/devis_analyzer.py` avec une fonction `analyze_references(references_extraites: list, references_dir: Path) -> dict` qui:

1. **Prend en entree** la liste `references_extraites` produite par `parse_devis` (Plan 03-01) -- chaque element a `code`, `quantite`, `section`.

2. **Pour chaque reference**, chercher le code de base (sans suffixe revetement) dans les fichiers MD:
   - Extraire le suffixe revetement s'il existe: le code peut se terminer par `-GE`, `-GR`, `-DA`, `-IN`, `-PP`, `-RP`, `-RS`, `-ST`, `-STP` (codes de revetement.md)
   - Exemple: `PM-D-H-75-GE` -> code_base = `PM-D-H-75`, revetement = `GE`
   - Exemple: `SPMSE-1967` -> code_base = `SPMSE-1967`, revetement = None
   - Charger la liste des codes revetement valides depuis revetement.md via md_parser pour construire la liste des suffixes dynamiquement (ne PAS hardcoder)

3. **Chercher le code_base** dans les fichiers MD via `md_parser.find_product(code_base, references_dir)`:
   - Si trouve: extraire la famille du produit
   - Si pas trouve: essayer aussi avec le code complet (certains codes incluent naturellement des lettres qui ressemblent a des suffixes revetement)
   - Si toujours pas trouve: marquer comme `inconnu`

4. **Detecter les produits necessitant un revetement:**
   - **Cas 1 - Suffixe explicite**: le code a un suffixe revetement (-GE, -GR, etc.) -> revetement = le suffixe
   - **Cas 2 - Sorbonne autoportante**: le produit est dans la famille Sorbonne ET son code commence par "S-A" (Sorbonne Autoportante) -> signaler qu'un revetement est necessaire mais pas specifie dans le code (le revetement sera dans la "Liste des revetements" de la dimension du produit, generalement "Glace emaillee, Gres")
   - Ne PAS forcer un revetement pour les paillasses sans suffixe (le suffixe est toujours present quand un revetement specifique est commande)

5. **Agreger les quantites**: un meme code peut apparaitre dans plusieurs sections. Creer un resume par code unique avec la quantite totale.

6. **Retourner un dictionnaire:**
```python
{
    "produits": [
        {
            "code_devis": "PM-D-H-75-GE",
            "code_base": "PM-D-H-75",
            "famille": "Paillasse",
            "quantite_totale": 10.63,
            "revetement": {"code": "GE", "nom": "Glace emaillee"},
            "occurrences": [
                {"section": "PAILLASSE HUMIDE", "quantite": 8.23},
                {"section": "PAILLASSE SECHE", "quantite": 2.40}
            ],
            "statut": "trouve"
        },
        {
            "code_devis": "SPMSE-1967",
            "code_base": "SPMSE-1967",
            "famille": "Equipement",
            "quantite_totale": 10.63,
            "revetement": null,
            "occurrences": [...],
            "statut": "trouve"
        },
        {
            "code_devis": "XYZ-INCONNU",
            "code_base": "XYZ-INCONNU",
            "famille": null,
            "quantite_totale": 1,
            "revetement": null,
            "occurrences": [...],
            "statut": "inconnu"
        }
    ],
    "resume": {
        "total_references": 8,
        "trouvees": 6,
        "inconnues": 2,
        "avec_revetement": 1,
        "familles": {"Paillasse": 2, "Equipement": 3, "Meubles": 1}
    },
    "alertes": [
        "Reference inconnue: XYZ-INCONNU (section: PAILLASSE HUMIDE)",
        "Sorbonne autoportante S-A detectee: revetement a confirmer avec le client"
    ],
    "revetements_necessaires": [
        {"code": "GE", "nom": "Glace emaillee", "pour_produits": ["PM-D-H-75-GE"]}
    ]
}
```

**Recuperation du nom complet du revetement:**
- Pour chaque code revetement detecte (GE, GR, etc.), chercher le produit correspondant dans revetement.md via `md_parser.find_product(code_revetement, references_dir)`
- Extraire le titre pour avoir le nom complet (ex: "GE - Glace emaillee" -> "Glace emaillee")

**Le module est une pure library** (pas de print/input, comme md_parser.py).
Utiliser les imports depuis md_parser:
