  <files>src/gendoc/parsers/image_handler.py</files>
  <action>
Create `src/gendoc/parsers/image_handler.py` with two functions:

**1. `copy_product_images(source_paths: list[str], famille: str, images_dir: Path) -> list[dict]`**

Takes a list of absolute source file paths provided by the user, copies each to `images_dir/{famille}/`, and returns a list of image dicts in the MD format.

Logic:
- For each source path in source_paths:
  - Validate the source file exists (skip with warning if not)
  - Extract filename from source path
  - Build target: `images_dir / famille / filename`
  - Copy using `shutil.copy2(source, target)` (preserves metadata)
  - Build image dict with keys:
    - `position`: empty string (user can set via update_reference later)
    - `chemin`: `Delagrave/images/{famille}/{filename}` (relative path as stored in MD)
    - `chemin_original`: the original source_path (for traceability)
    - `left`, `top`, `width`, `height`: 0.0 (defaults, user sets via update)
    - `shape_index`: empty string
- Return list of image dicts
- If a target file already exists, overwrite it (user is providing updated images)
- Raise no exceptions — return partial results if some files fail to copy, log failures in returned dict (add `error` key to dict for failed items)

**2. `remove_product_images(product: dict, images_dir: Path) -> dict`**

Takes a product dict (as returned by `remove_product_from_family`) and removes its image files from disk.

Logic:
- Extract `images` list from product dict
- Extract `famille` from product dict
- For each image dict in images:
  - Get `chemin` field (relative path like `Delagrave/images/{famille}/filename.png`)
  - Resolve to absolute path: `images_dir / famille / filename` where filename = Path(chemin).name
  - If file exists, delete with `Path.unlink()`
  - If file doesn't exist, skip silently
- Return stats dict: `{"removed": N, "not_found": M, "errors": K, "details": [...]}`
- Do NOT delete the family images directory itself (other products may use it)
- Catch exceptions per-file to avoid one failure blocking others

Use `from pathlib import Path` and `import shutil`. This is a pure library module (no print statements, no logging — follows md_writer pattern). Include docstrings with type hints.
