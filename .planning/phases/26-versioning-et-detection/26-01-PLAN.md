  <action>
Creer `src/gendoc/utils/version_checker.py` avec deux fonctions principales:

**get_local_version() -> str:**
- Utiliser `importlib.metadata.version('gendoc-delagrave')` pour lire la version depuis pyproject.toml
- Fallback: si importlib.metadata echoue (package pas installe en mode editable), lire directement pyproject.toml avec un regex sur `version = "X.Y.Z"`
- Retourner la version string (ex: "2.0.0")

**check_for_update(github_repo: str, github_token: str | None = None) -> dict | None:**
- Parametres: `github_repo` au format "owner/repo" (ex: "RemyBONNIN/gendoc-delagrave"), `github_token` optionnel pour repo prive
- Appeler GitHub REST API: `GET https://api.github.com/repos/{owner}/{repo}/tags?per_page=1`
- Headers: `Accept: application/vnd.github.v3+json`, `Authorization: token {github_token}` si token fourni
- Utiliser `urllib.request` (pas de dependance externe) avec timeout de 5 secondes
- Parser la reponse JSON pour extraire le nom du dernier tag (format "vX.Y.Z" ou "X.Y.Z")
- Comparer avec la version locale en utilisant une fonction helper `_parse_semver(version_str: str) -> tuple[int, int, int]` qui nettoie le prefixe "v" et split sur "."
- Si remote > local: retourner `{"needs_update": True, "local_version": "X.Y.Z", "remote_version": "X.Y.Z", "release_url": "https://github.com/{repo}/releases/latest"}`
- Si local >= remote: retourner `{"needs_update": False, "local_version": "X.Y.Z", "remote_version": "X.Y.Z"}`
- Si TOUTE erreur (reseau, parsing, token invalide, timeout): retourner None (echec silencieux)
- Wrapper try/except au niveau le plus haut -- JAMAIS de crash, JAMAIS de print

**_parse_semver(version_str: str) -> tuple[int, int, int]:**
- Strip le prefixe "v" si present
- Split sur "." et convertir en int
- Si parsing echoue, lever ValueError (l'appelant gere)

**_format_update_message(update_info: dict) -> str:**
- Generer un message clair en francais pour stderr
- Format: "[gendoc] Mise a jour disponible: v{local} -> v{remote}\n[gendoc] Voir: {release_url}"
- Si needs_update est False, retourner chaine vide

Aussi: mettre a jour `src/gendoc/__init__.py` pour synchroniser `__version__` avec pyproject.toml. Remplacer la valeur hardcodee "0.1.0" par une lecture dynamique:

