  <action>
Create `DEPLOY.md` in the project root. The guide must be written in **French** (the users are French-speaking Delagrave employees). The guide must be clear, actionable, and completable in under 15 minutes.

Structure the guide with these sections:

**1. Pre-requis** (~2 min)
- Python 3.10+ installe (verifier avec `python --version`)
- Claude CLI installe et configure (acces au compte Anthropic)
- Acces au lecteur reseau partage contenant le dossier Delagrave (references, images, template)

**2. Installation du package** (~3 min)
- Copier le dossier du projet sur le poste local (par exemple `C:\gendoc\`)
- Ouvrir un terminal dans le dossier copie
- Executer `pip install -e .`
- Verifier: `python -c "from gendoc.mcp.server import main; print('OK')"`

**3. Configuration gendoc.json** (~3 min)
- Creer un fichier `gendoc.json` dans le dossier du projet (ou dans `%USERPROFILE%` sous le nom `.gendoc.json`)
- Contenu:
```json
{
    "network_share_path": "S:\\Delagrave",
    "admin": false
}
```
- Expliquer `network_share_path`: chemin vers le dossier Delagrave partage (UNC ou lettre lecteur). Ce dossier doit contenir: `references/`, `images/`, `Modele fiches - Powerpoint/`
- Expliquer `admin`: mettre `true` uniquement sur le poste administrateur qui gere le catalogue. Les postes utilisateurs gardent `false`.
- Verifier: `python -c "from gendoc.utils.config_loader import load_config; c = load_config(); print('Config OK:', c['references_dir'])"`

**4. Enregistrement MCP pour Claude CLI** (~3 min)
- Creer un fichier `.mcp.json` a la racine du projet
- Contenu:
```json
{
    "mcpServers": {
        "gendoc": {
            "command": "python",
            "args": ["-m", "gendoc.mcp.server"],
            "cwd": "C:/gendoc",
            "env": {
                "PYTHONPATH": "C:/gendoc/src"
            }
        }
    }
}
```
- Adapter `cwd` et `PYTHONPATH` au chemin reel du projet sur le poste
- Expliquer que Claude CLI detecte automatiquement `.mcp.json` au lancement dans le dossier du projet
- Verification: ouvrir Claude CLI dans le dossier du projet, les outils `gendoc` doivent apparaitre dans les outils MCP disponibles

**5. Test de generation** (~3 min)
- Ouvrir Claude CLI dans le dossier du projet
- Tester la recherche: demander a Claude "Cherche la reference PM-D-H-75"
- Tester la liste: demander a Claude "Liste les familles de produits"
- Tester la generation: demander a Claude "Genere les fiches pour le devis [chemin_vers_un_devis.pdf]"
- Resultat attendu: un dossier `output/` cree avec le PowerPoint et le LOG.md

**6. Depannage** (reference)
- "Config file not found" -> creer gendoc.json (voir section 3)
- "network_share_path does not exist" -> verifier le chemin reseau, verifier que le lecteur est mappe
- "Required subdirectory 'references/' not found" -> le chemin pointe vers le mauvais dossier
- "Required template file not found" -> verifier que le template .potm est present dans "Modele fiches - Powerpoint/"
- "Operation reservee a l'administrateur" -> le poste est en mode utilisateur (admin=false), CRUD bloque volontairement
- Les outils MCP n'apparaissent pas -> verifier .mcp.json, verifier PYTHONPATH, relancer Claude CLI

**7. Structure du dossier partage** (reference)
- Decrire la structure attendue du dossier Delagrave sur le reseau:
```
Delagrave/
  references/          <- Fichiers MD (11 familles + _index.md)
  images/              <- Images produits par famille
    paillasse/
    sorbonne/
    ...
  Modele fiches - Powerpoint/
    Modele fiche technique vide - Ind J.potm
```

Write the entire guide in DEPLOY.md. Use clear formatting, numbered steps, and code blocks for all commands. Keep it concise — no unnecessary prose. The user should be able to follow it mechanically.
