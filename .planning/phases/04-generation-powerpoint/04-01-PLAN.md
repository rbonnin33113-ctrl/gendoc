**1. Template Loading (`load_template(template_path) -> Presentation`):**
The template is a `.potm` (macro-enabled) at `Delagrave/Modele fiches - Powerpoint/Modele fiche technique vide - Ind J.potm`.
python-pptx cannot open .potm directly. Must:
- Copy .potm to a temp file with .pptx extension (use `tempfile.NamedTemporaryFile`)
- Open as zipfile, read all entries
- Write to new zip, replacing content type:
  - `application/vnd.ms-powerpoint.template.macroEnabled.main+xml` -> `application/vnd.openxmlformats-officedocument.presentationml.presentation.main+xml`
- Remove `ppt/vbaProject.bin` entry (skip it when copying)
- Also update `[Content_Types].xml` to remove the vbaProject content type entry
- Load the fixed .pptx with `Presentation(fixed_path)`
- Return the Presentation object

**2. Family-to-Layout Index Mapping:**
```python
FAMILY_LAYOUT_MAP = {
    'paillasse': 1,   # Fiche technique profil paillasse
    'sorbonne': 2,    # Fiche technique sorbonne
    'revetement': 3,  # Fiche technique revetement
    'meubles': 4,     # Fiche technique meuble
    'tables-en': 4,   # Same layout as meubles
    'equipement': 5,  # Fiche technique equipement
    'elec-sorb': 5,   # Same layout as equipement
    'complements': 5,  # Same layout as equipement
}
```

**3. VBA Shape Index to python-pptx Placeholder Index Mapping:**

The MD data stores VBA shape indices (1-based, positional). These map to python-pptx placeholder idx as follows:

For **paillasse** (layout 1):
- VBA shape 1 -> idx 13 (TEXTE)
- VBA shape 2 -> idx 0 (TITRE)
- VBA shape 3 -> idx 14 (Revetements)
- VBA shape 4 -> idx 15 (REF)
- VBA shape 5 -> idx 16 (dim 1)
- VBA shape 6 -> idx 17 (dim 2)
- VBA shape 7 -> idx 18 (dim 3)
- VBA shape 8 -> idx 19 (dim 4)
- VBA shape 9 -> idx 20 (dim 5)
- VBA shape 10 -> idx 21 (page)

For **sorbonne** (layout 2):
- VBA shape 1 -> idx 13 (TEXTE)
- VBA shape 2 -> idx 0 (TITRE)
- VBA shape 3 -> idx 14 (Revetements)
- VBA shape 4 -> idx 15 (REF)
- VBA shape 5 -> idx 16 (dim 1)
- VBA shape 6 -> idx 17 (dim 2)
- VBA shape 7 -> idx 18 (dim 3)
- VBA shape 8 -> idx 19 (dim 4)
- VBA shape 9 -> idx 20 (dim 5)
- VBA shape 10 -> idx 23 (dim 6)
- VBA shape 11 -> idx 28 (dim 7)
- VBA shape 12 -> idx 29 (page)

For **revetement** (layout 3):
- VBA shape 1 -> idx 13 (TEXTE)
- VBA shape 2 -> idx 0 (TITRE)
- VBA shape 3 -> idx 14 (Mise en oeuvre / Applications)
- VBA shape 4 -> idx 15 (REF)
- VBA shape 5 -> idx 16 (Finition)
- VBA shape 6 -> idx 17 (Applications)
- VBA shape 7 -> idx 18 (page)

For **meubles** (layout 4):
- VBA shape 1 -> idx 13 (TEXTE)
- VBA shape 2 -> idx 0 (TITRE)
- VBA shape 3 -> idx 15 (REF)
- VBA shape 4 -> idx 16 (page)

For **equipement** (layout 5):
- VBA shape 1 -> idx 0 (TITRE)
- VBA shape 2 -> idx 15 (Reference)
- VBA shape 3 -> idx 16 (page)

Store these as a dictionary: `VBA_TO_PLACEHOLDER = { 'paillasse': {1: 13, 2: 0, 3: 14, 4: 15, ...}, ... }`

**4. Populate Text Placeholders (`_populate_slide(slide, product, family)`):**
For each product:
a) Get the layout index from FAMILY_LAYOUT_MAP using product['famille'].lower()
b) Add a slide using `prs.slide_layouts[layout_index]`
c) Map product data to placeholders:
   - **Titre**: Set placeholder idx=0 text to product['titre']
   - **Texte**: Set placeholder idx=13 text to product['texte']
   - **REF**: Set placeholder idx=15 text to product['ref']
   - **Revetements/Dimensions**: Use product['dimensions'] list. Each dimension has a `shape_index` (VBA). Convert VBA shape_index to placeholder idx using VBA_TO_PLACEHOLDER[family]. Set the placeholder text to:
     - If dimension has a prefix: `f"{prefix}{valeur}"`
     - If no prefix: just `valeur`
   - **Metadata PPTX fields**: Use product['metadata_pptx'] to identify which fields are TEXTE type with shape_index. For each, find the corresponding data in product fields and populate the placeholder.

For populating placeholders, iterate over `slide.placeholders` and find by `placeholder.placeholder_format.idx`. If a placeholder idx exists in the mapping, set its `text_frame.text` to the value. Handle missing placeholders gracefully (some products may not have all dimension fields).

IMPORTANT: When setting text, preserve the existing font formatting by accessing `placeholder.text_frame.paragraphs[0].runs` if needed. For simplicity in v1, setting `.text_frame.text = value` is acceptable.

**5. Image Insertion (`_insert_images(slide, product, project_root)`):**
Images are NOT in placeholders — they are positioned as separate shapes using absolute coordinates from the MD data.

For each image in product['images']:
- Build absolute path: `project_root / image['chemin']`
- Check if image file exists (skip `.missing` files and non-existent paths)
- If image exists, use `slide.shapes.add_picture(str(image_path), left, top, width, height)`
- Convert position values from the MD data. The values in the MD are in VBA points (1 point = 12700 EMUs). Use `pptx.util.Pt()` to convert: `Pt(image['left'])`, `Pt(image['top'])`, `Pt(image['width'])`.
- For height: if height is 0 or empty, let python-pptx auto-calculate from aspect ratio by passing `width` only (omit height parameter).

**6. Coating Auto-Generation (`_add_revetement_slides(prs, revetement_codes, references_dir, project_root)`):**
For each coating code in the revetement_codes list:
- Look up the coating product in revetement.md using find_product(code, references_dir)
- If found, generate a slide using layout 3 (revetement layout)
- Populate text and images using the same _populate_slide and _insert_images functions

**7. Main Orchestrator (`generate_presentation(product_codes, output_path, references_dir, template_path, project_root, mode="FTI")`):**
- Load template with load_template()
- For each product_code:
  - Look up product data with find_product(code, references_dir)
  - If code contains a coating suffix (e.g., "PM-D-H-75-GE"), also look up the base code (strip suffix)
  - Get family from product data
  - If family not in FAMILY_LAYOUT_MAP, skip (log warning)
  - If family is 'fiches-existantes', skip (Phase 5 handles pre-existing .pptx merge)
  - Create slide and populate
- Collect all unique revetement codes from products that have coatings
- Generate revetement slides for each unique coating
- Save presentation to output_path
- Return dict with: slides_generated (int), revetements_added (list), skipped (list of skipped codes with reasons)

Follow the pattern from existing modules: pure library, no print/input, comprehensive docstrings, type hints.
