  <files>src/gendoc/mcp/server.py</files>
  <action>
Create a helper function `_require_admin(operation_name: str) -> str | None` in server.py that:
- Checks `_config["admin"]` (the module-level config loaded at import)
- If admin is False, returns a JSON error string: `{"error": "Operation reservee a l'administrateur", "resume": "ECHEC {operation_name}: mode administrateur requis"}`
- If admin is True, returns None (no error, proceed)

Add the guard at the very top of each CRUD tool function body (before any input validation):
1. `add_reference`: Add `if (err := _require_admin("ajout")): return err` as first line
2. `update_reference`: Add `if (err := _require_admin("modification")): return err` as first line
3. `delete_reference`: Add `if (err := _require_admin("suppression")): return err` as first line

The guard MUST be before any other logic (before input validation, before try/except). This ensures non-admin users never reach business logic.

Do NOT modify any read-only tools (lookup_reference, search_references, list_families, analyze_devis, generate_slides, preview_generation, open_sp_selector, load_sp_selection, create_custom_product).
  </action>
