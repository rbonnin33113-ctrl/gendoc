**Markdown output format -- REQUIRED section headers (exact French strings, non-negotiable):**

The following exact French headers are REQUIRED and MUST be used verbatim. Tests assert on these exact strings. Do NOT translate, paraphrase, or modify them in any way:

- `# Log d'Execution Pipeline` -- main title (line 1, REQUIRED EXACT)
- `## Parametres d'Entree` -- input parameters table (REQUIRED EXACT)
- `## Etapes du Pipeline` -- pipeline steps (REQUIRED EXACT)
- `## Erreurs Rencontrees` -- errors (REQUIRED EXACT)
- `## Solutions Appliquees` -- solutions (REQUIRED EXACT)

Each step rendered as: `### {N}. {step_name} -- {OK|ECHOUE|INTERROMPU} ({duration:.2f}s)`

If result dict provided, render as bullet list under the step heading.

Error entries include context key-values and optional traceback in a fenced code block.

Overall status line (after the title): `**Statut:** OK | ERREURS | ECHOUE`
- "OK" = no errors and no failed steps
- "ERREURS" = some errors but pipeline completed (at least one step succeeded)
- "ECHOUE" = critical failure (a step has ECHOUE status)

**Important details:**
- Use `time.perf_counter()` for duration measurements (not datetime subtraction -- perf_counter is monotonic and more precise)
- The `write_log()` method must create the logs subdirectory if it does not exist (use `mkdir(parents=True, exist_ok=True)`)
- Log file name: `{YYYYMMDD_HHMMSS}_pipeline.md`
- The class should be safe to use even if `write_log()` is never called (no side effects until write)
- Handle edge cases: step started but never ended (mark as "INTERROMPU"), no steps logged
- `write_log()` must be safe to call multiple times (idempotent -- overwrites same file)
- Keep the module pure library (no global state, no prints)

```python
def _safe_write_log() -> str | None:
    """Write the current pipeline log and reset. Returns log path or None."""
    global _current_logger
    if _current_logger is None:
        return None
    try:
        log_path = _current_logger.write_log()
        return str(log_path)
    except Exception:
        return None
    finally:
        _current_logger = None
```

```python
async def generate_slides(...) -> str:
    global _current_logger
    step = None
    try:
        # ... existing path resolution and validation ...

        if _current_logger:
            _current_logger.set_input_params(
                product_codes=product_codes,
                output_path=str(output),
                devis_info=devis_info
            )
            step = _current_logger.start_step("Generation PPTX")

        # Hot-reload and call generator
        _generate = _reload_generators()
        result = _generate(
            product_codes=product_codes,
            output_path=output,
            references_dir=REFERENCES_DIR,
            template_path=TEMPLATE_PATH,
            project_root=PROJECT_ROOT,
            mode=mode,
            devis_info=devis_info,
            custom_products=custom_products_list
        )

        # Log per-product errors from result (products skipped during generation)
        # The _generate() function catches per-product errors internally and adds
        # them to result["skipped"]. We log each one individually here.
        if _current_logger:
            for s in result.get("skipped", []):
                _current_logger.log_error(
                    f"Produit ignore: {s['code']}",
                    context={"code": s["code"], "reason": s["reason"]}
                )
            _current_logger.end_step(step, result={
                "slides_generated": result.get("slides_generated", 0),
                "total_pages": result.get("total_pages", 0),
                "revetements_added": result.get("revetements_added", 0),
                "skipped": len(result.get("skipped", []))
            })

        # Write log in success path and capture log_path for the response
        if _current_logger:
            log_path = _current_logger.write_log()
            result['log_path'] = str(log_path)
            _current_logger = None

        result['output_path'] = str(output)
        return json.dumps(result, ensure_ascii=False, indent=2)

    except Exception as e:
        if _current_logger and step:
            _current_logger.fail_step(step, str(e), traceback_str=traceback.format_exc())
        log_path = _safe_write_log()
        resp = {"error": f"Erreur de generation: {str(e)}"}
        if log_path:
            resp["log_path"] = log_path
        return json.dumps(resp, ensure_ascii=False)

    finally:
        # Safety net: if logger was not written by try or except, write now
        # This handles edge cases where neither path completed normally
        if _current_logger:
            _safe_write_log()
```

**Why this pattern works for all 3 critical issues:**
- **Issue #1 (per-product errors):** `result["skipped"]` is iterated after `_generate()` returns, logging each skipped product individually via `log_error()`. The generator already captures per-product errors (missing image, lookup failure) as `skipped` entries -- we surface them in the log.
- **Issue #2 (early failures):** `analyze_devis`, `preview_generation`, `open_sp_selector`, and `load_sp_selection` ALL have except blocks that call `_safe_write_log()` to write partial logs. The log captures whatever steps completed before the failure.
- **Issue #3 (try/finally):** `generate_slides` uses try/except/finally. The `try` block writes the log on success. The `except` block writes it on failure. The `finally` block is a safety net for edge cases where neither path completed.

**Important:** All logger calls must be wrapped in `if _current_logger:` guards so tools work fine standalone (without a preceding analyze_devis call). Use `global _current_logger` in each function that modifies it.

**Do NOT change function signatures or return types** -- only add logging instrumentation inside existing try/except blocks.
