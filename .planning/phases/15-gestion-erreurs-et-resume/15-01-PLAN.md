<objective>
Make the generation pipeline resilient to per-product errors by wrapping slide builds in try/except, collecting image warnings, and propagating them through the result chain.

Purpose: Currently, `build_product_slide` returns None and image errors are silently swallowed via `continue`. If `build_product_slide` throws an unexpected exception, the entire pipeline crashes. This plan makes each product slide build fault-tolerant and surfaces per-product warnings for downstream logging.

Output: Modified generators where build_product_slide returns `list[str]` warnings, assemble_document collects them, and generate_presentation includes them in the result dict.
</objective>
