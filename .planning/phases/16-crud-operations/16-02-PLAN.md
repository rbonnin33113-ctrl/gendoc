**Part A: Add functions to md_writer.py**

Add two new functions to `src/gendoc/parsers/md_writer.py`:

1. **`update_product_in_family(code: str, updates: dict, references_dir: Path) -> dict`**
   - Find the product using `find_product(code, references_dir)` — return error dict if not found
   - Determine the family file from the found product's `famille` field
   - Read the entire family MD file content
   - Locate the section for this product code: starts with `\n## {code}\n` and ends at the next `\n## ` or end of file
   - Apply updates to the product dict: for each key in `updates`, replace the value in the product dict. Supported keys: `titre`, `texte`, `ref`, `dimensions`, `images`, `metadata_pptx`. Ignore unknown keys.
   - Re-format the product section using `format_product_section()` with the updated product
   - Replace the old section content in the file with the new formatted section
   - Write the updated file back (UTF-8)
   - Verify the update by re-reading with `find_product()` — log warning if verification fails
   - Return result dict: `{"success": True, "code": code, "famille": famille, "updated_fields": list(updates.keys())}` or error dict

   **Critical implementation detail for section replacement:**
   - Use regex to find the section boundaries: `re.search(r'\n## ' + re.escape(code) + r'\n', content)` for start
   - The section ends at the next `\n## ` (start of next product) or at end of file
   - Replace from section start (including `\n## {code}\n`) to section end (exclusive of next `\n## `)
   - The replacement string should be `\n` + format_product_section(updated_product) + `\n`
   - Handle edge case: product is the FIRST section after the header (no leading `\n## ` prefix — section starts with `## ` at line beginning after header)

2. **`delete_product_from_family(code: str, references_dir: Path) -> dict`**
   - Find the product using `find_product(code, references_dir)` — return error dict if not found
   - Determine the family file from the found product's `famille` field
   - Read the entire family MD file content
   - Locate the section for this product code (same approach as update)
   - Remove the entire section (including the `---` separator after it)
   - Write the updated file back (UTF-8)
   - Verify deletion by checking `find_product()` returns None
   - Return result dict: `{"success": True, "code": code, "famille": famille}` or error dict
