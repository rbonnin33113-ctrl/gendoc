Add three new functions to md_writer.py:

**1. validate_product_exists(code: str, references_dir: Path) -> tuple[bool, str, str]**
- Uses md_parser.find_product(code, references_dir)
- Returns (True, family_name, family_file_path) if product exists
- Returns (False, "", "") if product not found
- Example: `exists, family, path = validate_product_exists("PM-D-H-75", refs_dir)`

**2. update_product_in_family(code: str, updates: Dict[str, Any], references_dir: Path) -> Path**
- Validates product exists using validate_product_exists (raises ValueError if not found)
- Reads entire family file into memory
- Splits by product sections using regex (same pattern as md_parser: `\n## ([A-Za-z0-9_. /+-]+)\n`)
- Locates target product section by code (case-insensitive match)
- Applies updates to product dict:
  - For scalar fields (code, ref, titre, texte): replace value
  - For list fields (dimensions, images, metadata_pptx): replace entire list (not merge)
- Regenerates product section using format_product_section() from Plan 16-01
- Reconstructs file content (header + all products with updated section)
- Writes back to family file (overwrites entire file)
- Returns Path to modified family file

**3. delete_product_from_family(code: str, references_dir: Path) -> tuple[Path, str]**
- Validates product exists using validate_product_exists (raises ValueError if not found)
- Reads entire family file into memory
- Splits by product sections (same regex as update)
- Filters out target product section (case-insensitive code match)
- Reconstructs file content (header + remaining products)
- Writes back to family file (overwrites entire file)
- Returns (family_file_path, removed_family_name)

**Implementation notes:**
- UTF-8 encoding for all file reads/writes
- Preserve file header (first section before first `## CODE`)
- Handle edge cases: last product in file, only product in file
- Maintain product separator: `---\n\n` between products
- Raise ValueError with clear message if product not found
- Follow existing md_writer code style (type hints, docstrings, no I/O)

**Error handling:**
- Product not found → ValueError with code and searched families
- File read error → OSError with path
- File write error → OSError with path

```python
@mcp.tool()
async def update_reference(
    code: str,
    updates: str
) -> str:
    """
    Update an existing product reference.

    Args:
        code: Product code to update
        updates: JSON string with fields to update. Supported fields:
                 ref, titre, texte, dimensions (list), images (list), metadata_pptx (list).
                 Example: {"titre": "New title", "texte": "Updated description"}

    Returns:
        JSON string with success status, updated fields, and resume.

    Example:
        update_reference("PM-D-H-75", '{"titre": "New Title"}') -> {"success": true, ...}
    """
    from gendoc.parsers.md_writer import (
        update_product_in_family,
        validate_product_exists
    )
    import json

    # Parse updates JSON
    try:
        updates_dict = json.loads(updates)
    except json.JSONDecodeError as e:
        return json.dumps({
            "error": f"Invalid JSON in updates: {str(e)}"
        }, ensure_ascii=False)

    # Validate product exists
    exists, family, family_path = validate_product_exists(code, REFERENCES_DIR)
    if not exists:
        return json.dumps({
            "error": f"Product not found: {code}"
        }, ensure_ascii=False)

    # Perform update
    try:
        updated_path = update_product_in_family(code, updates_dict, REFERENCES_DIR)
        return json.dumps({
            "success": True,
            "code": code,
            "famille": family,
            "updated_fields": list(updates_dict.keys()),
            "file_path": str(updated_path),
            "resume": f"Reference {code} mise a jour ({len(updates_dict)} champ(s))"
        }, ensure_ascii=False, indent=2)
    except (ValueError, OSError) as e:
        return json.dumps({
            "error": f"Update failed: {str(e)}"
        }, ensure_ascii=False)
```

**2. delete_reference MCP tool:**

```python
@mcp.tool()
async def delete_reference(code: str) -> str:
    """
    Delete a product reference from the catalog.

    Args:
        code: Product code to delete

    Returns:
        JSON string with success status, famille, and resume.

    Example:
        delete_reference("PM-TEST") -> {"success": true, "code": "PM-TEST", ...}
    """
    from gendoc.parsers.md_writer import (
        delete_product_from_family,
        validate_product_exists
    )
    import json

    # Validate product exists
    exists, family, family_path = validate_product_exists(code, REFERENCES_DIR)
    if not exists:
        return json.dumps({
            "error": f"Product not found: {code}"
        }, ensure_ascii=False)

    # Perform deletion
    try:
        deleted_path, deleted_family = delete_product_from_family(code, REFERENCES_DIR)
        return json.dumps({
            "success": True,
            "code": code,
            "famille": deleted_family,
            "file_path": str(deleted_path),
            "resume": f"Reference {code} supprimee de la famille {deleted_family}"
        }, ensure_ascii=False, indent=2)
    except (ValueError, OSError) as e:
        return json.dumps({
            "error": f"Delete failed: {str(e)}"
        }, ensure_ascii=False)
```

**Key points:**
- Do NOT use PipelineLogger (catalog edits are not pipeline operations)
- Return `resume` field for user feedback (compact French)
- Follow existing MCP tool patterns (async, JSON return, error handling)
- Import md_writer functions inside tool (not at module level) to avoid circular imports
