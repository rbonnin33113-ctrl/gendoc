  <name>Task 1: Create md_writer.py with product formatting and append functions</name>
  <files>src/gendoc/parsers/md_writer.py</files>
  <action>
Create `src/gendoc/parsers/md_writer.py` as a pure library module (no I/O except file writing) following the same pattern as md_parser.py.

Implement these functions:

1. **`format_product_section(product: dict) -> str`**
   - Takes a product dict with keys: code (required), titre (required), famille (required), ref (optional, default ""), texte (optional, default ""), dimensions (optional, default []), images (optional, default []), metadata_pptx (optional, default [])
   - Returns a formatted MD string for one product section matching the exact format in existing MD files
   - Format must include:
     ```
     ## {code}

     | Champ | Valeur |
     |-------|--------|
     | code | {code} |
     | ref | {ref} |
     | titre | {titre} |
     | famille | {famille} |

     ### Texte

     {texte or "Aucune"}

     ### Dimensions

     | Dimension | Valeur | Prefix | Shape Index |
     |-----------|--------|--------|-------------|
     {dimension rows if any}

     ### Images

     | Position | Chemin | Chemin Original | Left | Top | Width | Height | Shape Index |
     |----------|--------|-----------------|------|-----|-------|--------|-------------|
     {image rows if any}

     ### Metadata PowerPoint

     | Champ | Type | Prefix | Shape Index |
     |-------|------|--------|-------------|
     {metadata rows if any}

     ---
     ```
   - The trailing `---` separator is required between products
   - Empty tables (no rows) must still include the header row and separator row

2. **`append_product_to_family(product: dict, references_dir: Path) -> dict`**
   - Validates required fields: code, titre, famille
   - Checks for duplicate code using `find_product()` from md_parser — returns error dict if duplicate found
   - Determines target file: `references_dir / f"{famille.lower()}.md"`
   - If file exists: appends the formatted section to the end of the file (after a newline)
   - If file does NOT exist: creates it with a header block matching existing format:
     ```
     # {Famille title-cased}

     > Managed by gendoc CRUD
     > Date: {current date YYYY-MM-DD}
     > Total references: 1
     ```
     Then appends the product section
   - Returns a result dict: `{"success": True, "code": code, "famille": famille, "file": str(filepath)}` on success
   - Returns error dict: `{"success": False, "error": "message"}` on failure

Important implementation notes:
- Use `from gendoc.parsers.md_parser import find_product` for duplicate detection
- The module must be importable as a library (no `if __name__ == "__main__"` block needed)
- Use UTF-8 encoding when writing files (matching md_parser read encoding)
- Add module docstring explaining this is the write counterpart to md_parser.py
- Add type hints and docstrings to all public functions
  </action>
