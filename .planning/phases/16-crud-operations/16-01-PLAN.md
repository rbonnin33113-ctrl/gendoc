  <name>Task 1: Create MD Writer Module</name>
  <files>src/gendoc/parsers/md_writer.py</files>
  <action>
Create md_writer.py as pure library module (no I/O output, complements md_parser.py):

**Core Functions:**

1. `format_product_section(product: Dict[str, Any]) -> str`
   - Takes product dict (code, ref, titre, famille, texte, dimensions, images, metadata_pptx)
   - Returns MD string matching exact format:
     ```
     ## {CODE}

     | Champ | Valeur |
     |-------|--------|
     | code | {code} |
     | ref | {ref} |
     | titre | {titre} |
     | famille | {famille} |

     ### Texte

     {texte}

     ### Dimensions

     | Dimension | Valeur | Prefix | Shape Index |
     |-----------|--------|--------|-------------|
     {for each dim in dimensions}

     ### Images

     | Position | Chemin | Chemin Original | Left | Top | Width | Height | Shape Index |
     |----------|--------|-----------------|------|-----|-------|--------|-------------|
     {for each img in images}

     ### Metadata PowerPoint

     | Champ | Type | Prefix | Shape Index |
     |-------|------|--------|-------------|
     {for each meta in metadata_pptx}

     ---
     ```
   - Handle empty sections gracefully (dimensions=[], images=[], texte="")
   - Preserve multiline titre values (ref MUST use ` |` suffix if multiline)

2. `validate_product_unique(code: str, references_dir: Path) -> tuple[bool, str]`
   - Uses md_parser.find_product(code, references_dir)
   - Returns (True, "") if code is unique
   - Returns (False, "Code {code} exists in {family}") if duplicate

3. `write_product_to_family(product: Dict[str, Any], references_dir: Path) -> Path`
   - Validates product has minimum fields: code, titre, famille
   - Validates code is unique (raises ValueError if duplicate)
   - Determines family file path: references_dir / f"{product['famille'].lower()}.md"
   - Creates family file if it doesn't exist (with header: `# {Famille}\n\n`)
   - Appends formatted product section using format_product_section()
   - Returns Path to modified family file

**Key constraints:**
- Pure library (no print/input, only raises exceptions)
- UTF-8 encoding for all file operations
- Preserve existing file content exactly (append only)
- Follow md_parser.py's coding style (type hints, docstrings)

**Error handling:**
- Raise ValueError for missing required fields (code, titre, famille)
- Raise ValueError for duplicate codes
- Raise OSError for file write failures
