  <name>Task 2: Add extract_sp_designations function and integrate into analyze_devis (EXT-01, EXT-02)</name>
  <files>src/gendoc/parsers/devis_analyzer.py</files>
  <action>
  Two additions to `src/gendoc/parsers/devis_analyzer.py`:

  **1. Create extract_sp_designations() function (EXT-01)**

  Add a new function `extract_sp_designations(pages_text: List[str], sp_codes: List[str]) -> Dict[str, str]` that extracts the designation text for each SP code from the raw PDF text.

  The PDF text format for articles is:
  ```
  SPMOB-25355 Paillasse Murale - Dosseret ht 100mm - Pietement H 30 x 30 - UN 1
  Longueur 3500mm - Profondeur utile 600mm - Haut. 850mm -
  Tube a ailette Ht 40mm - Revetement Resine de Synthese
  ```

  Algorithm:
  - For each page (skip page 0 = cover), scan lines
  - When a line starts with an SP code (case-insensitive match), extract the designation:
    a. Take text after the code on the same line
    b. Strip trailing quantity pattern: strip `UN \d+` or just `\d+` from the end of the first line (the quantity column that pdfplumber merges into the text)
    c. Continue reading subsequent lines as continuation of the designation UNTIL:
       - Next line starts with a known article code (matches the extract_article_codes regex pattern: starts with uppercase letter/digit, 4+ chars, alphanumeric with hyphens)
       - OR line contains "Sous-total" or "Page " or other exclusion keywords
       - OR line is empty
    d. Join all designation lines with " " (space), collapsing multiple spaces
  - Return dict mapping SP code -> designation text (first occurrence wins, since same SP code appears multiple times in the devis with identical designation)

  **2. Integrate designation extraction into analyze_devis() (EXT-02)**

  In `analyze_devis()`, after `classify_codes()` returns:
  - Collect all SP codes from `classification['speciaux']`
  - Call `extract_sp_designations(pages_text, sp_codes)` to get designations
  - Enrich each entry in `classification['speciaux']` with a `designation` field containing the extracted text
  - If no designation found for a code, set `designation` to empty string ""

  The final `speciaux` list entries should have: `{code, famille, prefix, designation}`
  </action>
